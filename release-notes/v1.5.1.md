Restart as administrator from inside PingerPlot, for full TCP and UDP traceroute.

**On 1.4.x or 1.5.0?** PingerPlot offers this update by itself (or ⋯ → **Check for updates**): click **Install and restart**. Otherwise: [`PingerPlot-Setup.exe`](https://github.com/jamesccupps/PingerPlot/releases/download/v1.5.1/PingerPlot-Setup.exe) (installs for your Windows user, no admin prompt) or [`PingerPlot-win64.zip`](https://github.com/jamesccupps/PingerPlot/releases/download/v1.5.1/PingerPlot-win64.zip) (portable). Scoop: `scoop update pingerplot`. On Linux there's nothing new. The downloads are code-signed by James Cupps; `SHA256SUMS.txt` lists every file's hash.

### Added

- **Restart as administrator** without hunting for the shortcut: **⋯ → Restart as administrator**, the same in the tray menu and **Settings → App**, and a button beside a target that stopped because full TCP or UDP traceroute needs it. Windows asks first, naming the publisher, and the elevated copy picks up the same targets. The title bar says "(Administrator)" while it runs that way. For the installed, portable and Scoop copies; from source, `launch.ps1 -Elevated` does it.

### Fixed

- **With a copy running as administrator, opening PingerPlot again started a second copy** that probed everything twice. It now finds the running copy.
- **The Start menu shortcut did nothing visible while an administrator copy was running.** It now brings that window forward.
- On a first run, the History page could say "no such table" for a moment; it now shows an empty history until there is one.
