PingerPlot on Linux, properly, and three fixes for everyone.

**On 1.4.0 or 1.4.1?** PingerPlot offers this update by itself (or ⋯ → **Check for updates**): click **Install and restart**. Otherwise: [`PingerPlot-Setup.exe`](https://github.com/jamesccupps/PingerPlot/releases/download/v1.4.2/PingerPlot-Setup.exe) (installs for your Windows user, no admin prompt) or [`PingerPlot-win64.zip`](https://github.com/jamesccupps/PingerPlot/releases/download/v1.4.2/PingerPlot-win64.zip) (portable). Not code-signed: *Windows protected your PC* → **More info → Run anyway**, and compare with `SHA256SUMS.txt`.

**On Linux:** install Tk from your distribution, then `pipx install git+https://github.com/jamesccupps/PingerPlot` and run `pingerplot`. Details in the [README](https://github.com/jamesccupps/PingerPlot#linux).

### Linux

- **One `pipx` command** to install it; it checks for updates daily and says to run `pipx reinstall pingerplot`.
- **Show in the applications menu** and **Start when you sign in**, in Settings.
- **Alert notifications** through `notify-send`, and a bell.
- **Match the system** follows your desktop's light or dark setting.
- Without Tk, it says which package to install instead of crashing.
- Still Windows-only: the notification-area icon (closing the window quits on Linux) and full TCP/UDP traceroute.

### Fixed, everywhere

- Long hop names in the Timeline ran into the loss column; they're now shortened with "…" to fit.
- Two messages named 1.3 settings ("Engine options", "Final hop only"); they name the current ones.
- Turning alert notifications on no longer replays the alerts from while they were off.

The full list is in the [CHANGELOG](https://github.com/jamesccupps/PingerPlot/blob/main/CHANGELOG.md).
