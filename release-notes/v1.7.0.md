An error log, alerts that say where on the path the trouble is, trouble several targets share, keyboard access, and a TCP/UDP capture that leaves the network card out of promiscuous mode.

**On 1.4.x, 1.5.x or 1.6.x?** PingerPlot offers this update by itself (or ⋯ → **Check for updates**): click **Install and restart**. If you're running it as administrator, start it normally first. Otherwise: [`PingerPlot-Setup.exe`](https://github.com/jamesccupps/PingerPlot/releases/download/v1.7.0/PingerPlot-Setup.exe) (installs for your Windows user, no admin prompt) or [`PingerPlot-win64.zip`](https://github.com/jamesccupps/PingerPlot/releases/download/v1.7.0/PingerPlot-win64.zip) (portable). Scoop: `scoop update pingerplot`. On Linux: `pipx install pingerplot` (new: PingerPlot is on PyPI), or `pipx upgrade pingerplot`. The downloads are code-signed by James Cupps; `SHA256SUMS.txt` lists every file's hash.

### Added

- **An error log.** The installed app has no console, so its errors and warnings went nowhere, and a copy that quit early or stopped recording left no trace. They now go to `error.log` in the settings folder (the headless runner's to `headless-error.log`), with when PingerPlot started, resumed its targets and quit, and why. Web addresses in it are cut to their host, so it's safe to attach to an issue.
- **Alerts say where the trouble is.** An alert's Events entry and webhook carry the Map's verdict ("Loss reaching the destination starts in Chicago, US (hop 7, 12%)"), and the webhook payload has the places as data in a new `where` list. The headless runner's alerts say it too.
- **Trouble several targets share.** When loss reaching the destination starts at the same router on more than one target's path, the Map says so: it's that router or something before it, often your own side, not the destinations.
- **The keyboard reaches everything.** Tabs take the focus (Return or Space chooses, Left and Right move along), the target list works like a list box (Up and Down change the target, the Menu key opens its menu), Ctrl+1 to Ctrl+4 open Hops, Timeline, Map and Events, Ctrl+, opens Settings, and every control shows a focus ring.
- **PingerPlot is on PyPI**: `pipx install pingerplot`.

### Changed

- **Full TCP/UDP traceroute no longer puts the network card in promiscuous mode.** Its capture switched promiscuous mode on and off every round, about 30 times a trace, which security software can flag. It now captures at the IP level, seeing only what's addressed to this computer, and counts an ICMP error only if it was addressed to the address the probes leave from.

### Fixed

- **An update while the headless runner ran from PingerPlot's folder** (a Task Scheduler task) couldn't replace its files, and the window had already quit, leaving nothing running. PingerPlot now says to stop the runner first and keeps going.
- **On Linux, a second launch started a second PingerPlot** that probed every target twice. Linux and macOS now hold a lock as Windows does, and a second launch shows the first copy's window.
- Light corners on disabled, hovered or pressed buttons.
