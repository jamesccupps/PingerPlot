More trustworthy numbers, and no more silent failures.

**Download:** [`PingerPlot.exe`](https://github.com/jamesccupps/PingerPlot/releases/download/v1.3.3/PingerPlot.exe) (the app) or [`pingerplot-headless.exe`](https://github.com/jamesccupps/PingerPlot/releases/download/v1.3.3/pingerplot-headless.exe) (no window, for Task Scheduler). Neither needs Python. They aren't code-signed, so Windows may say *Windows protected your PC*: **More info → Run anyway**, and compare the file with `SHA256SUMS.txt`.

### Changed

- **Jitter is the average change from one reply to the next**, not the standard deviation of RTT. It's what the MOS score expects: a reroute from a steady 20 ms to a steady 60 ms is a latency change, not jitter. The Jitter column, exports, reports and MOS change with it; saved sessions are recomputed when loaded.

### Fixed: numbers the app reports

- A reroute could raise a false packet-loss alert on a healthy destination: its alert window held a router's rate-limited replies. The window now counts only what the destination itself answered.
- **Linux:** a busy app could add tens of milliseconds to every reading. Replies are now timed by the kernel.
- All targets wrote into one probe log; each now gets its own file (`probe_<target>.csv`).
- Each target's settings now survive a restart, instead of every target coming back with the last-edited one's.
- **macOS:** probes running together could take each other's replies; each reply is now matched to its probe.
- The probe log keeps sub-millisecond times.

### Fixed: problems that went unreported

- A source IP this PC doesn't have is refused in every mode, with a message saying so. TCP used to fall back to the default route and UDP ignored it.
- A probe log open in Excel no longer stops rollover silently, or reopens the file on every probe.
- A webhook that can't be delivered says so in the Events tab (naming only the host).
- The headless runner prints events: alerts, route changes and warnings.
- Map lookups that failed while offline are retried instead of staying blank.
- Pressing **Add / Start** again during a slow DNS lookup no longer wipes the new run.
- One error in a redraw no longer freezes the window, and **Stop all** no longer stops targets one at a time.
- A damaged session file is loaded as far as it's readable instead of crashing.

### Security

- The *auto-start at logon* task now registers and checks the Python it actually runs, and runs it without your
  per-user Python settings or packages.
- Release builds run their build tools from a hash-pinned list, in a job that can't publish; only a separate job
  holds that permission.
