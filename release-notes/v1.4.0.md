PingerPlot as a proper Windows app: an installer, a portable zip, signed updates, the notification area, and a new window. The engine and its numbers are unchanged, and your 1.3 settings and saved sessions carry over.

**Download:** [`PingerPlot-Setup.exe`](https://github.com/jamesccupps/PingerPlot/releases/download/v1.4.0/PingerPlot-Setup.exe) (recommended: installs for your Windows user, no admin prompt) or [`PingerPlot-win64.zip`](https://github.com/jamesccupps/PingerPlot/releases/download/v1.4.0/PingerPlot-win64.zip) (portable: keeps its settings in its own folder). The app isn't code-signed, so Windows may say *Windows protected your PC*: **More info → Run anyway**, and compare the file with `SHA256SUMS.txt`. Coming from 1.3's `PingerPlot.exe`? Run the installer; your settings are already where it looks.

### New

- **An installer and a portable zip.** A Start menu shortcut, upgrades in place, uninstalls from Settings → Apps. The headless runner, `pingerplot-headless.exe`, is beside the app in both.
- **Signed updates.** It checks GitHub once a day and installs a new version with one click, only if the download carries the release signature built into the app and matches its signed checksum. Turn it off in Settings → Updates.
- **Runs in the background.** Closing the window keeps monitoring from the notification area. The icon gets a red badge while a target alerts, and a notification when an alert starts or ends opens that target.
- **Start with Windows**, in Settings or the tray menu: straight to the notification area, resuming your targets.
- **One copy at a time**: starting it again shows the running window.
- **Follows Windows' light or dark theme** (new installs; 1.3 users keep dark).

### Changed

- **A new window.** Each target is a card; the selected one shows its MOS, the destination's numbers, alerts, and Hops, Timeline, Map and Events. The ⋯ menu at the top right has export, sessions, comparison and updates.
- **Settings is a page**, every option described, instead of the toolbar and the Engine dialog. To change one running target, right-click it → **Edit settings**.
- The Map labels each place once and no longer piles labels on top of each other.

### Fixed

- A closed dialog could stall a probe round for seconds while Python cleaned it up on the wrong thread.
